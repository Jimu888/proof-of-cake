# 第一轮设计共同输入

项目：Proof of Cake（临时代号）。受众：熟悉钱包的加密用户。目标：挑选原创艺术作品，填写朋友的 Agent ID，以自己的身份署名送礼，并让朋友看到一份有仪式感的礼物。

本轮交付：三个独立 HTML 高保真原型、六个方向缩略图总览、1440×900 电脑首屏/整页截图和 375×812 手机截图。均为本地设计探索，不接生产后端。每版统一包含选礼、填写 .ai 名字、选择祝福、礼物预览、空收藏与返回比较入口。

假设：品牌名称未定；中文为主要操作语言；没有收到用户原作文件；用程序绘制的三件概念作品；不展示虚构艺术家、价格、成交量或链上哈希。`.ai` 输入只校验格式，不查询身份。展示预览分享链接只在同一本地服务器可访问。

Form 五问：叙事是从作品到赠送；观看距离是桌面和手机；视觉温度三版分别克制、明快、沉静；容量为一个精选作品与少量目录；母题来自生日蜡烛、绕太阳一圈和收藏关系。
