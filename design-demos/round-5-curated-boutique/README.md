# 第五轮：精品店式首页

用户要求更高级、更克制，避免杂货铺与市场感。本轮以精选数量、留白、字体与主次关系调整首页，不修改前端。

- [冷白精选展陈](01-white-curation.png)：最接近实体展陈，有装裱和陈设；这些道具不是产品交付内容，可能弱化数字艺术平台的识别，不作为首选。
- [暗色私享展厅](02-black-salon.png)：安静暗色、两件主次作品、克制的进入挑选入口。
- [编辑式精选系列](03-editorial-collection.png)：浅色、开放的作品编排，下一段开始展示另一类作品。

三张共享“首页精选开场”的基本结构，主要比较气质、材质处理和信息密度，不宣称三个完全不同的交互方案。图内文案、图标和作品重现都是概念占位。像素和卡通仍可作为作品存在；没有统一作品风格。

图片均为内置 ImageGen 生成，1536×1024，未经后期修改。提示词见 prompts.json；所有方向 approved=false。原有页面未改变。

下一步等待用户选择或纠正，不直接将某张图转成代码，也不把图内物理画框、陈设、装裱或生成文案当作已确认功能。
