# 第三轮：首页图片方向稿

本轮遵从用户要求，只生成图片，没有编写或修改前端网站。

1. [暗色加密标本](01-cryptographic-specimen.png)：单件作品居中，物理金属与细密计算网格，逐件浏览入口靠近作品。
2. [冷白协议档案](02-protocol-paper.png)：冷白、银灰、文档般的留白，作品与操作形成不对称结构。
3. [暗场信号](03-dark-signal.png)：点云重建与暗场材质，作品占据主要视野，旁侧保留挑选和赠送操作。

图片均为 1536×1024，由内置 ImageGen 分别生成。未经后期修改。最终提示词见 prompts.json；每张图片的 .json sidecar 标记 approved=false。

## 观察与使用边界

三张都保留了单件浏览、换下一件、朋友身份和准备礼物的主线；视觉从卡通转向成熟低饱和的计算艺术。

生成图中的作品、文字、导航和按钮均是方向占位，不代表已实现的网站。第二张出现“独一件”等生成文案，未获得用户确认，不可当作产品事实直接用于正式前端；实现时应替换成已确认的作品与版数说明。所有图片文字也需要在实现阶段由真实文本与控件重建。

当前只选视觉和构图，不批准价格、版数、品牌字标或链上功能。
