## 三维作品下一步

创作者提供 GLB/glTF 模型后，可采用 GLTFLoader 接入统一作品查看器；元数据区分 image、video、model 媒介与预览图，模型只在交互时加载。须验证体积、网格/材质复杂度、资源来源、移动端帧率和不支持 WebGL 的降级。单张透明 PNG 不包含背部几何，图片生成工具产生的不同视角也不等同于一个真实三维模型。

可先委托或单独制作一件可用的宇航猫三维作品，再接入，不为凑供给而替所有图片制作模型。

## 验证

生产构建、类型检查、既有 4 项业务测试。浏览器检查见 qa-report.json 和 screenshots；检查 1440/768/390/320 宽度、两件展示、完整赠送预览、三维拖动导致渲染变化、复位、真实盒盖展开、品牌页无溢出、以及关闭 WebGL 后图片降级。三维测试使用 Chromium 软件渲染，不代表所有手机 GPU 已验证。无真实钱包或结算测试。
