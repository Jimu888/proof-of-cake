# CryptoGift 黑金交互 Demo

2026-11-01，按用户新提供的两张参考图实现；这是实现方向的授权，不代表已经确认正式品牌或所有设计细节。

## 打开

仓库根目录 `npm run dev -- --port 3190`。

- `/`：首页、精选系列、分类与名称搜索、作品详情、赠言和收礼信息。
- `/receive`：礼盒、开箱、作品展示、详情、完整欣赏、留言和会话内收藏。

首页可点作品完成一遍流程；直接打开收礼页则显示默认宇航猫。

## 实现边界

Next.js / React 页面；字体、排版、按钮、筛选、输入、导航、玻璃框和光环均由代码实现。ImageGen 生成背景、礼盒、猫、花和空间场景。礼盒、猫有真实透明通道。生成素材及完整提示词位于 `public/cryptogift/`。原有水墨图片只作为异质作品展示，保留原色与完整比例，未假定作者或授权可公开发行。

当前使用参考图的 CryptoGift 临时字标，不改变仓库的 Proof of Cake 项目代号。展示作品、价格、署名、分类均为占位，未宣称真实艺术家、限量、合约、Token ID 或购买成功。

赠言与收礼输入只经本地 sessionStorage 在当前标签页中传递，不上传演示 API、放入 URL 或提交仓库。请只填示例资料。关闭会话后不作为平台礼物记录保留；收藏也仅在此会话有效。这里没有跨设备分享、通知、钱包登录、地址解析、付款、铸造或真实发送。自由赠言仅用于本地 Demo，不代表正式版本已决定开放公开自由内容。

开箱是 CSS 过渡与生成图片配合的展示动画，不是完整 3D 物理拆盒。减少动态效果偏好会跳过长动画。
