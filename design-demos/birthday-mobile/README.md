# 手机收礼体验验证

《计划之外》手机优先优化，保持原有礼盒→三维世界的同场景衔接与祝福。

- 手机竖屏：作品在上，15px 祝福在下；考虑安全区，短屏可滚动，不截字。
- 横屏：作品与信并排；单指左右拖动，纵向手势可滚动短页面。
- 手机渲染分辨率上限 1.25、阴影 1024、单个 Draco 解码 worker。
- 手机星光光晕按原模型星点投影，在独立合成层闪烁；开盒完成后，静止作品不因闪烁重绘。拖动时更新星点位置并避开主体区域。
- 保留加载进度、慢网等待、失败静态预览与重试；增加模型预载，检查没有重复下载。

证据：`qa-report.json` 为 Chromium 模拟视口/触摸矩阵（320×568、360×640、390×844、430×932、667×375、844×390、768×1024、1440×900），在版式与触摸调整后完成。最终星光优化后另以 `loading-qa.json` 核对触摸拖动、闪烁、GPU 不因闪烁持续绘制、单次下载和错误状态。

没有真实 iPhone/Android 硬件测试。已尝试本机 WebKit，但引擎启动 Bus error，未能验证 WebKit；不能把 Chromium 模拟称为真机 Safari 验证。
