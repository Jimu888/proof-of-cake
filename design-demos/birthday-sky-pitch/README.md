# 补充星空与扩大上下角度

按用户要求，在背景留白新增 28 个细小星点，原模型中的太阳和 34 颗星星保留不动。新增星点覆盖完整画面，位于透明三维画布后方，由主体自然遮挡；礼盒提示、展开后的信件与底部手势提示周围自动留空。每点独立相位缓慢闪烁，减少动态效果时保持静态，不增加 WebGL 持续重绘。

上下角度从 ±4° 扩大为 ±7°，左右仍为 ±15°，保留约 1–1.67 倍细节放大。可完整容纳页面的触屏视口使用单指上下/左右旋转；短屏仍允许纵向滚动，避免祝福不可达。

Chromium 手机触控模拟验证 390×844 的纵向旋转和 320×568 的滚动，以及桌面 1440×900 视图；范围检查使用合成方向键事件，星点闪烁对比开盒前像素，并检查新增点不落在信件区域。慢网、单次下载、闪烁、静止不重绘与错误回退回归通过。不是实机测试。
