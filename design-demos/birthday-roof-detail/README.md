# 车顶细节：网页显示改进

用户指出车顶图案难以看清。本轮仅修改网页端渲染与交互，未修改 Blender 工程、原始图片或 GLB 文件。当前模型 SHA256 仍为 1da4cb77d6b0a9a1f5a572f9525f49486d2c19c4e73413fc75e1a1e07ec1b68d。

车顶材质为 Web Roof • user supplied birthday cat print，使用 bake_0 的 1024×1024 烘焙图。静止时提高渲染分辨率，触控交互时降档，松手 160ms 后恢复；对手机设置 250 万绘制像素预算，最高像素比 2.5。车顶贴图使用设备支持的最大各向异性采样。

允许有限双指/滚轮缩放，范围约 1–1.67 倍；仍禁止平移，保留左右15°、上下4°。键盘加减键也可查看细节。手机和鼠标分别显示合适的简短操作提示，未增加工具栏按钮。

证据：Chromium 在 390×844、320×568、844×390 和 1440×900 验证双指/滚轮/键盘放大、缩放边界、互动低档/静止高清恢复、页面无错误与原 GLB 哈希不变。另重跑慢网、单次下载、星光、静止不重绘和失败回退验证。没有真机 Safari/Android 验证。

网页改进不会恢复贴图中已经丢失的细节；如放大后仍不足，需要另行从源素材重新输出更高质量的车顶贴图。本轮没有执行该操作。
