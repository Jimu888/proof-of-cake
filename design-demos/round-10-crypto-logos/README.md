# Mement · 加密文化 Logo 研究

2026-11-01 用户认为上一轮还不满意，希望增加加密文化、加密学元素与设计语言。

`/brand-lab` 展示五个新方向；`/brand-lab/classic` 保留上一轮可直接对照，未将任何新 Logo 设为已批准。

- A 签名曲线：曲线交点、个人签名与 m 的连笔。视觉创作，不是具体密码算法的数学曲线。
- B 记忆之树：Merkle 树的分叉节点和汇聚路径。
- C 哈希印记：真正以 UTF-8 字符串 `Mement` 的 SHA-256 摘要前 15 个二进制位逐行填入 5×3 单元，左右镜像成 5×5 格。参数及完整摘要见 public/brand-studies/mement-v3/hash-source.json。属于固定品牌纹样，不把这段截断图案当成安全指纹、二维码或身份验证。
- D 密码朋克徽记：切面、负形和尖端组成的公会式 M，强调个人主权与独立创作者气质。无指定社群或现成项目标志引用。
- E 承诺封印：封存与揭示的视觉隐喻；图形不是已实现加密承诺协议的声明。

标记均为透明原生 SVG，目录 public/brand-studies/mement-v3，未使用栅格生成工具。字标使用现有 Hanken、Teko 与系统衬线/等宽字体做方向研究，下载为图形标记。每组展示深浅底、导航组合、48/24/16px。网站名称暂定 Mement，主站标记仍是过渡占位。
