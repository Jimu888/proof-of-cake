# 本地修订：统一暮光场景与真实开箱

用户反馈：黑金包装与蓝紫作品像两个网站，转场生硬；星光开启比关闭暗且看不到闪烁。

## 视觉与转场

临时生日体验统一采用作品的暮光、暖日与纸色，不影响产品首页。页头、页尾、开箱前后背景都采用同一配色。移除旧黑金礼盒图片的使用，换成原生 Three.js 纸盒，与用户模型共用一个 Canvas、相机与灯光。

同一场景中：点击后纸盒盖上抬，等待动画与模型载入完成，再把作品从盒内位置由小展开到原始比例，纸盒逐渐消隐。背景、太阳、星光、云层与镜头不切换；标题与控件在展开尾声再出现。所有 WebGL 过渡均有明确停止条件，静止后按需重绘。保留原 GLB 与左右15度查看范围，未改动模型文件或导出工程。

减少动态偏好下缩短开箱，关闭默认闪烁；WebGL 不可用时显示纸盒降级，再进入作品静态预览。文案仍为临时通用祝福，署名 jimu.ai。

## 星光修复

旧 CSS 动画只把 opacity 从原值降至 .12 后回升，所以平均更暗；星点小、周期长，变化不明显，也易受全局减少动态规则影响。

改用独立 Web Animations：静态亮点的亮度为基线，只向1增亮并伴随轻微放大，保留小光晕，部分星点有十字辉光。开启不改变天空、太阳、模型光照或整体曝光。关闭取消动画，恢复固定亮度。页面隐藏时暂停，卸载时取消；用户主动开启可覆盖其减少动态默认选择。CSS 旧星点动画明确禁用，避免多个动画相互覆盖。
