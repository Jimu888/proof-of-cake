# 第二轮共同输入

用户否定首轮三个方向：“都是非常普通的设计”；要求“小众”“强烈的个人色彩或者作者的风格”。本轮不复用通用画廊、生日商品台、收藏仪表盘的主结构。保持直接赠送、.ai 网络身份、精选作品和演示边界。

三张完整初稿：存在证明、只给你、怪诞标本园。统一在 1440×900 和 375×812 验证。每张都能切换概念作品、输入名字、预览礼物与打开分享预览。首轮继续保留，正式 UI 未定。

素材：一件生成的银色蜡烛结雕塑；两件程序化矢量概念作品。生成素材只用于设计探索，不代表用户原作，也不宣称签约艺术家。参考设计思维而非复制任何既有作品。

Form：一份心意从一个身份抵达另一个身份；观众近距离操作；三张分别仪式、反叛、怪趣；单屏一个主要动作；母题为存在证明、单向赠予、保留个体差异。
