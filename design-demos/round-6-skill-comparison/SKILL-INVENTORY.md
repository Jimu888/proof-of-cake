# 本次 Skill 盘点

## 分别试做的六个设计方法

| Skill | 本次实际采用的阶段 | 独立方向 |
| --- | --- | --- |
| Frontend Design | 阅读指引；主题、token 与构图计划；按 brief 自我审视 | 私人献辞，平台识别来自赠予关系与字体 |
| UI/UX Pro Max | 运行 --design-system；剔除不适配结果；一次更窄 style 检索 | 极简 Swiss 结构与清晰选礼入口 |
| Taste Skill | 阅读 page 流程；实际抽取三个方向，选定并生成 full sheet | uneven-photographs / Three prints, one line，Archivo 与深森林色 |
| Hallmark | 实际 deal 三个主题；看 Atelier 样张并读主题文档 | Atelier，Sentient light 与 Hanken，低声量艺术沙龙 |
| Impeccable | 用 sh 成功运行 context 与 concept-seed；读取新工作和模式指引 | 个人献辞服务，作品先行与渐进揭示 |
| 花叔 Design | 阅读网页/方向/排印方法，结合用户偏好档案 | 中文与西文排印的生辰画册式节奏 |

本轮只比较设计阶段。用户已要求先看图片，故不运行各 Skill 的整套生产代码、站点发布或所有方向决策流程。Impeccable 的图片在会话内呈现，未另建选择网页，也未进行生产 build-phase；花叔 Design 未扩展为单独三套完整 HTML；这均为图片方法对比的范围裁剪，不能说成完整工作流验收。

## 不适配建议与工具边界

UI/UX Pro Max 首次 design-system 返回 Feature-Rich Showcase / Liquid Glass / 多 CTA / social proof，与本项目精品店要求及无真实背书事实冲突，未采用，也没有写成项目规范。一次缩小检索得到 active 的 minimalism-and-swiss-style；使用其空间、单色、可读性原则，其他精品店处理是本项目设计判断，不宣称检索已提供专属奢侈品系统。

Taste 的 dealt sheet 含氛围摄影建议，但本项目展示的是现有艺术作品，不加入无关山水图库，也不统一调色作品。采用其实际布局、字体与配色角色，素材使用已知作品与生成概念图。

Hallmark 选 Atelier 的轻、静、排印与 Gallery Hang，不把官网做成香水、实体画廊或样张中的虚构品牌。主题 source: /Users/jimu/.codex/skills/hallmark/references/themes/atelier.md。

Impeccable context 已正确识别 docs/PRODUCT.md，context 运行成功。它提示产品记录仍是旧 schema；此提示不阻塞本轮，没有擅自改写，可在用户需要时另做 init。没有声称运行 detector 或双代理 critique，也没有选择一个已批准的生产视觉系统。
