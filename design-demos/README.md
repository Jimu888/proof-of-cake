# 前端设计探索

这次只选方向，不替用户确定正式 UI。完整原型是独立静态 HTML，尚未迁入 Next.js 产品路由。

## 查看

在项目根目录执行：

```sh
python3 -m http.server 3188 --bind 127.0.0.1 --directory design-demos
```

打开 http://127.0.0.1:3188/index.html 比较 A/B/C。dir-1.html、dir-2.html、dir-3.html 也能直接以文件方式打开；分享/复制链接建议通过本地服务体验。

三个原型都能：选作品、切换主题、体验模拟身份、填写名字、选祝福、打开礼物预览、复制本地预览链接、查看空收藏。它们不调用真实钱包、数据库或链上接口；没有产生 NFT，刷新也不会保留模拟登录。

所有绘画素材都是本轮概念 SVG，不是用户自己的原作。没有虚构价格或链上交易。截图和设计来源见 spec.md、directions.md、brand-spec.md。

## 验证

- 1440、768、375 宽度浏览器检查，无页面横向溢出。
- 三版均验证无效名字提示、正常预览、主题筛选、模拟身份、直接打开分享页、复制链接和空收藏。
- qa-report.json 保存结果。scripts/design_qa.py 可复跑，需要 Python Playwright 与 Chromium；先启动本地服务。
- skill 的静态设计检查无红灯或模板装饰；三个版本的结构与色板比较通过。
- 非正式视觉验收；等待用户选择，尚不作为生产前端。

参考截图仅供私有仓库内设计研究。不要作为作品素材发布。选择以后把用户原话记录到 direction-approved.md。
