# 产品范围

## 产品一句话

为加密用户挑选、赠送和珍藏生日数字艺术礼物。

## 已确认方向

- 早期服务加密用户；以 Binance Agent ID 作为优先身份入口。
- 作品来自平台原创和签约艺术家，不开放任意用户上传或修改作品。
- 生肖、星座、生日等题材可逐步加入，不要求首发凑齐全部系列。
- 知道对方身份或钱包地址即可直接赠送；收礼人不必提前注册或点击领取。
- 钱包登录后读取身份署名；不能靠手动填写冒充发送人。
- 礼物展示页、分享链接帮助朋友发现已送达的作品。
- 每份礼物保留作品、送礼身份、收礼地址、赠送时间和祝福编号。
- 赠送后不可转让是初始产品意图，需在合约阶段明确锁定与销毁规则。
- 钱包身份作为网络身份使用，不要求平台建立真人资料。

## 第一版闭环

浏览精选作品 → 钱包登录 → 输入收礼 Agent ID → 核对地址及礼物 → 付款/确认赠送 → 链上确认 → 分享礼物页面 → 收礼人查看和管理展厅。

首次登录是管理展厅的条件，不是接收 NFT 的条件。未登录也能浏览获准公开的礼物。

## 当前建议，尚未当成最终决定

- 首发用预设祝福，暂时不开放自由输入。
- 未登录展示页不暴露任何非公开资料。
- 第一个系列少量作品，数量、价格、版数和购买限额另定。
- 单链优先；BNB Smart Chain 是候选，需先完成 Agentic Wallet 的 NFT 能力验证。

## 暂不做

二级交易、平台代币、DAO 治理、开放创作者入驻、多链发行、定制聊天、推荐算法。签约艺术家先由运营手动上架。

## 核心页面（待实现）

作品目录 / 作品详情与赠送表单 / 送出状态与分享 / 礼物详情 / 个人展厅。

## 验证指标

送礼是否完成；收礼人是否发现并打开；对方对礼物的反馈；是否有第二位愿意购买的送礼人。访问链接不等于 NFT 已送达，重复访问不等于独立用户。
