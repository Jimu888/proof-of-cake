# Mement 体验与视觉精修任务单（v2）

> **用途**：供执行编码的 AI 模型直接读取并在 `proof-of-cake` 仓库内完成本轮精修。
> **核心原则**：延续「纯中性石墨黑当代画廊精品店」气质，严禁破坏现有 `/receive` 生日 3D 个例、`/ops/*` 后台及 16 项业务测试；所有链上操作仅限本地隔离链与 BSC 测试网 97。

## 一、首页街角橱窗：找回“橱窗纵深感”与显性上下滑动提示

1. **强化橱窗建筑纵深（`src/components/crypto-gift.tsx`、`src/app/platform.css`）**：
   - 首页第一屏橱窗的 3D 展示壁龛（`.vitrine-zodiac-niche`）**移除 36px 网格底纹**（网格仅保留在 `/series/zodiac` 专题赏玩台内），恢复纯中性深炭黑渐变内壁 + 更清晰的建筑内凹倒角阴影 + 顶部 4800K 柔和射灯光锥，让首页重新拥有“站在暮色街道外透过落地玻璃看美术馆壁龛”的高级纵深感。
2. **显性化“上下滑动切换橱窗”提示**：
   - 目前右侧 `↕ 上下滑切换` 过于隐蔽。请在首屏底部居中或右侧垂直索引旁，增加一枚克制但一眼可见的动态微提示（极细竖线 + 缓慢上下呼吸的微光点与文案：`上下滑动切换橱窗`），在用户完成第一次滑动后自动柔和淡出或保持极低透明度。

## 三、3D 生肖舞台视觉升级（缩小与概念预览图的质感差距）+ 移除红色印章

1. **彻底移除红色“天降鸿运”朱砂方框**：
   - 从 `src/components/zodiac-studio.tsx`（含 3D 赏玩台右上角、写信封缄弹窗右上角、取礼邀请函 Canvas）及 `src/app/platform.css` 中**彻底删除** `.zodiac-cinnabar-seal` 红色印章元素；四字吉语仅以极克制的等宽/衬线文字安静落在铭文卡落款处即可。
2. **升级 `src/components/zodiac-stage.tsx` 的 3D 光影与氛围质感**：
   - **环境反射（PMREM）**：使用 Three.js 内置 `RoomEnvironment` + `PMREMGenerator` 设置 `scene.environment`（适度 `environmentIntensity = 0.65`），让黑曜石、冰银与香槟金体素产生真实的暗调晶体与金属反光，杜绝暗面死黑。
   - **克制辉光后处理（UnrealBloomPass）**：接入 `EffectComposer` + `RenderPass` + `UnrealBloomPass`（`threshold: 0.72`, `strength: 0.42`, `radius: 0.55`），让眼眸、头顶空投棱镜、龙中央 0/1 方块和链上流光自然散发出接近预览图的高级柔光，同时不糊掉暗部细节。
   - **升级 2D 氛围粒子与背景层次**：在 3D 模型后方增加一层极柔和的径向背光晕与细微底部光场；将稀疏的大空心菱形改为**大小错落的微光星尘 + 极细发光几何微粒**，整体氛围更接近预览图的精致静谧感。

修改 `src/components/gift-checkout.tsx` 和 `src/components/zodiac-studio.tsx` 中的锁仓区块：

1. **统一视觉风格**：
   - 去掉原生的 `<fieldset>` 边框、原生白色复选框和突兀的默认 `<select>`。
   - 改造成与上方「信纸纸色」完全一致的极简建筑卡片：顶部采用极简自定义切换开关（Switch / Pill），内部输入采用极细底线输入框（与信纸卡片同语言）+ 统一的暗色下拉/币种切换按钮（`原生 BNB` / `自定义 BSC 代币`）。
2. **优化命名**：
   - 将偏生硬的“封入链上资产”统一更名为：**`随礼封存一份心意金（选填）`**（副标：`VAULTED GIFT · 支持 BNB 或任意 BSC 代币`）。
3. **必须明确展示给送礼人的核心规则提示**（放在开关展开后的醒目但克制的说明框内）：

   - **不可转让规则**：根据当前作品的真实策略动态明确提示（例如：「此礼物 NFT 为**永久不可转让**版本，专属于收礼人钱包，不可转售或转赠他人」）。

## 五、长按改为 `2 秒` + 新增「封装入盒过渡动画」

修改 `src/components/gift-checkout.tsx` 和 `src/components/zodiac-studio.tsx`：

1. **长按时长调整**：将 `SEAL_HOLD_MS` 从 `1200` 调整为整数 **`2000`（2 秒）**，按钮文案改为 `长按 2 秒 · 封缄并生成礼盒`，SVG 圆形钢印环内可极简显示倒计时或百分比进度。
2. **新增「封装入盒动画」（约 1.2–1.4 秒，不可直接生硬跳转）**：
   - 长按满 2 秒后，先进入 `sealing_animation` 过场状态：信纸卡片柔和收拢缩小 → 滑入一枚带顶部极细白光条的暗色封缄封套 → 居中浮现极简建筑落印 `SEALED · 已封缄`，同时触发极轻的一声落印音效（若用户未静音）→ 动画结束后再平滑展示「取礼邀请函与分享链接」结果页。

2. **纯粹、无干扰的收礼仪式界面**：
   - 页面上**不出现**顶部主导航、十二生肖选择栏、生日输入框、滤镜切换栏或“送礼”按钮；

## 八、隐形仪式感点睛：极克制 Web Audio 微声效（可选开关）

- 新建轻量工具 `src/lib/ritual-sound.ts`（纯原生 Web Audio API 合成，零外部音频文件依赖）：
  - `playSealStamp()`：长按 2 秒封缄完成时一声极轻沉稳的低频落印声；
  - `playUnsealSlide()`：划开封条启封时一声极细腻的短促气音/微鸣；
  - `playLightReveal()`：壁龛亮灯或 3D 拼装完成时一声极克制的空灵泛音。
- 在送礼/收礼页角落提供极简 `SOUND ON / OFF` 小开关（遵循浏览器自动播放策略，仅在用户主动交互后触发）。
