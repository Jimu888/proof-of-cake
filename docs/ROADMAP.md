# 开发路线

每一阶段只有一个可验收结果；完成后更新 STATUS，不因为新想法扩大当前阶段。

| 阶段 | 要做什么 | 完成标准 |
| --- | --- | --- |
| M0 项目底座 | 私有仓库、文档、目录、演示接口、自动检查 | 克隆后能安装、测试、构建；资料入口完整 |
| M1 可点击演示 | 作品目录、送礼表单、礼物详情与个人展厅；模拟身份和赠送 | 手机和电脑完整走一遍；醒目标明演示；刷新行为有定义 |
| M2 钱包能力验证 | 实测连接、登录证明、Agent ID 正反查、NFT 接收与合约调用 | 保存脱敏证据和测试步骤；明确可行接入方式；失败时给出替代方案 |
| M3 测试链闭环 | 数据库、测试支付、赠礼合约、确认任务、不可转让约束 | 测试 NFT 到目标钱包，重复请求不重复发，失败能恢复 |
| M4 小范围真实试用 | 真实原创作品和授权、最终价格、主网小额赠送、分享通知 | 第一笔真实送礼完成并拿到反馈；操作和恢复步骤齐备 |

M1 与 M2 可先后调整：页面演示不依赖钱包，但没有 M2 的证据不能宣称真实支付可行。暂不承诺完成日期或生产安全性。

## 下一次工作任务：M1

输入：用户已完成的原创作品（尚未复制到仓库）；目前产品文档。

产出：可点击的本地演示。先确定一个视觉方向，再实现作品 → 送出 → 礼物页完整流程。没有素材时可使用明确标注的占位内容，不冒充用户作品。模拟赠送不能生成真实到账提示或虚假交易链接。

后续待办：适配手机、空状态与失败状态、双击送出、分享链接打开和刷新、无钱包浏览、展厅隐藏。验收后再接真实钱包。
