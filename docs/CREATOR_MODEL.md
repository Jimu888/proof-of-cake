# 创作者合作与作品供给

2026-11-01 用户明确的产品方向。以下为合作原则与待实现设计，不是已签约条款或已运行结算系统。

## 供给与首发

精品路线，邀请艺术家、独立创作者或由平台原创，不开放任意上传。创作者带来作品与个人表达，平台共同策划、呈现并组织赠礼体验。

首发不需要大量品类。可以只有一个创作者、一件作品；前端有单件或少量作品的展示能力。当前两件示例只验证构图，不代表已签约、已授权发行或真实库存。

## 收入原则

作品转为 NFT，在购买并赠送时产生销售收入。主要收入归创作者，平台收取一部分服务或运营费用。具体比例、结算周期、网络费承担、税费及退款规则需要逐项确认，不擅自写入 80/20 等比例。

赠送后不可转让仍为产品初衷，所以首期收入设计围绕首次购买赠送，不把二级转售版税作为商业模式的前提。

## 发布前逐项确认

- 创作者展示身份、作品署名、授权范围与原文件。
- 作品媒介：图片 / 动画 / 视频 / 真正三维文件。
- NFT 发行数量、定价、接收链、赠送限制与元数据。
- 收款地址、创作者与平台分成、结算事件和争议处理。

这些信息在具体作品合作中确认，前端不虚构艺术家身份或合作数量。

## 后续系统落点

作品记录关联 Creator 和 AgreementVersion。订单冻结当次定价、创作者地址、平台费及分成规则版本，使用最小币种单位整数记账。浏览器不得自由提交这些金额作为可信定价。

实际赠送、支付经服务端链上事件核验后才产生可结算记录；失败、退款、重复事件有独立状态和幂等键。合约分账还是后端结算在支付方案验证时决定，当前不执行任何分账。最终数据库/合约设计需再评审，不将本说明误认为已实现。
