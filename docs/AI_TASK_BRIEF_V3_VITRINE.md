# Mement 首页街角橱窗视觉精修指令（v3 · 像素级还原高级橱窗感）

> **目标**：把当前首页 `/` 从“平面黑框 + 过曝发雾模型 + 杂乱标签”精准拉回到最初惊艳的 **「当代美术馆厚墙深嵌壁龛（Architectural Recessed Vitrine）」** 质感。
> **仅修改首页橱窗视觉、3D Hero 灯光参数与壁龛结构**，严禁破坏展厅、特展、送礼/收礼或测试。

---

## 1. 核心改造：用真正的“四面内凹建筑斜面”重构壁龛（`.boutique-niche` / `.vitrine-niche`）

当前壁龛只是一个模糊的平面黑框，没有墙体厚度。请用纯 CSS 几何做出真正的 **40cm 深嵌石材壁龛**：
- **壁龛外框与内凹斜面（4 面受光不同）**：
  - 壁龛内部增加 4 条明确的建筑内壁斜面（可用伪元素或 4 个轻量 `aria-hidden` 结构层，或 `border-width: 22px` 配合四边不同明度的纯中性深灰）：
    - 顶面（背光最深）：`#0c0d10`
    - 左右两侧斜面（柔和中灰受光）：`#1c1e23`
    - **底面台座（承接顶光最亮，建立雕塑托举感）**：`#272a30`（带顶部 1px 极细受光棱线 `rgba(255,255,255,0.14)`）
  - 内壁背景：纯中性深炭灰径向渐变（`radial-gradient(ellipse 65% 58% at 50% 34%, #24262c 0%, #15171b 58%, #0f1013 100%)`），**绝对不要发黄、发棕或灰蒙蒙的雾感**。
  - 外墙背景（`.boutique-vitrine`）：在页面正顶部增加一束宽广、干净的展厅顶光（`radial-gradient(ellipse 42% 30% at 50% 0%, rgba(255,255,255,0.095), transparent 72%)`），自然照亮壁龛上沿，四周平滑沉入 `#101114` 深石青炭黑。
- **壁龛比例与居中留白**：
  - 桌面端 `.vitrine-niche` 调整为更挺拔大气的画廊窗比例：`width: min(470px, 34vw); height: min(62svh, 560px);`，稳稳居中在视口视觉中心。

## 3. 治好 3D 未羊的“过曝灰雾”与“脚部贴底”问题（`src/components/zodiac-stage.tsx`）

- **压低过曝 Bloom（关键）**：
  - `UnrealBloomPass` 参数严格调整为：`threshold: 0.88`、`strength: 0.16`、`radius: 0.35`（原参数过强导致头顶空投方块、羊尾与光晕糊成一团白雾）。
- **拉远 `hero` 模式镜头，给雕塑四周留足画廊呼吸感**：
  - `mode === 'hero'` 时，`camera.position.set(0, 0.18, 5.75)`，`targetSize = 2.05`，确保羊头顶的空投棱镜与下方四只羊蹄距离壁龛上下边缘各有 15%+ 的干净留白，绝不贴底裁切！
- **保持纯中性画廊布光**：
  - 减弱暖黄 `warmFill` 强度（避免把整个壁龛染成脏黄色），以干净的冷白主光 + 冰银轮廓背光 + 适度 `RoomEnvironment`（`environmentIntensity = 0.55`）突出黑曜石与香槟金体素的锐利棱角。
