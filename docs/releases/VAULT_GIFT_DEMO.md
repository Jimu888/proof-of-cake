# 主题特展与内封资产

首页 `/#gifts` 打开常设陈列，`/#series` 打开主题特展。`/series/zodiac` 是生肖特展的固定入口，旧 `/zodiac` 链接的全部查询参数转发到新路径。已归档的龙、羊、马、牛及 PNG 预览通过资产接口读取。

普通作品的赠礼表单和生肖封缄弹窗可以选填内封资产。普通礼物的预览保存在本地订单。生肖礼物使用独立的 `/gift/zodiac` 分享与收礼页，原有生肖封缄链接会转入该页面。两类邀请函都附可扫码二维码。生肖销毁演示按住两秒确认，播放三维反向消散并在当前浏览器会话保留祝福、灰阶作品及演示赎回时间。

## 测试赠礼

在 `/ops` 审核并陈列作品，选择允许持有人销毁的发行规则。为作品准备并在钱包确认测试网部署，核验后绑定新发行版。旧测试合约与原有纯艺术品赠礼继续使用各自的发行记录。

新发行版使用 `MementVaultGift`，链 ID 固定为 97。钱包页可以按作品售价赠送纯艺术品，额外封入原生 tBNB，或在测试网 ERC-20 授权后封入代币。收礼页等三次确认后显示资金实际入账，并可引导当前持有人连接同一链上的钱包销毁赎回。销毁和转出在同一笔交易内完成。确认后收礼页仍显示祝福，以及实际到账和赎回交易。

售价收入按发行分成进入艺术家和平台的可提余额，内封资产单独记账。锁仓入账按转入余额差计算，赎回记录持有人实际到账。部分转账扣税代币支持按实际到账显示，暂停、白名单、余额重基或非标准扣款可能阻止赎回。合约转出失败时，销毁和账目会随交易回滚。测试币和模拟代币用于验证。

## 验证命令

```sh
npm run typecheck
npm test
npm run test:nft
node --test scripts/testnet-contract-test.mjs scripts/vault-gift-contract-test.mjs
node scripts/vault-gift-compile.mjs --check
npm run build
```

链 97 的本地隔离环境可配置 `MEMENT_LOCAL_TESTNET_RPC=http://127.0.0.1:端口`。单元测试和集成验证结果见 [状态记录](../STATUS.md)。
