# 生日礼物 NFT：BSC 发行方案（待实施）

当前仅本地演示，没有部署合约、上传素材、铸造、转账或核实收礼地址。网页顶部显示“NFT 赠送准备中”，不能从查询参数或未核验配置切换成已送达。

## 完整作品包含什么

- `public/birthday/birthday.glb`：主场景、太阳、34 颗星星、材质与内嵌贴图；没有动画片段。
- 互动网页：开盒、星星脉冲与光晕、渐变天空、云雾、拖动视角、文字、鼠标效果。只归档 GLB 不包含这些运行时效果。
- 建议 NFT 元数据的 `image` 指向作品封面，`animation_url` 指向自包含的完整 HTML 体验，`external_url` 指向方便访问的网页。钱包可能只展示封面，各客户端需要实测；不能保证钱包内直接运行 HTML。
- 将作品和全部网页依赖打包，用 IPFS 内容地址归档并持续 pin/备份。Cloudflare 可以作为访问入口；普通网页地址本身不保证持久性。上链的是归属与内容索引，约 19 MB 的模型不直接存入合约。

## 不可转让

建议 ERC-721 + ERC-5192，并在合约实际阻止所有后续地址间转移，而非只隐藏网页按钮。直接向收礼地址铸造唯一一枚，避免先铸造给发送者后锁住。建议无管理员解锁、无升级或任意移走接口；销毁策略另定，必须在发行前明确。不能通过换网页修改已经部署的合约规则。

绑定的是地址，换钱包或丢失控制权不能迁移；接收者仍可分享网页或复制模型。

## 实施顺序

1. 确定作品名称、最终祝福、收礼 BSC 地址，以及销毁策略。
2. 准备完整作品归档和元数据；确认哪些祝福可以公开后再上传。
3. 实现并测试合约：只铸造一枚、直接给收礼人、禁止全部后续转移和授权绕过、元数据冻结、无后台解锁通道。先 BSC 测试网验证。
4. 核对合约与费用并完成真实签名后，部署 BSC 主网、铸造到收礼地址，发送方支付 BNB gas。
5. 核对链 ID、交易回执、合约、Token ID、接收地址及 ownerOf/locked，再将网页提示接入真实链上状态并提供 BscScan 查看入口。交易失败/未确认不得标记送达；若未来所有者销毁，要区分赠送历史和当前持有状态。
6. 完成后分享网页；打开网页只播放体验，不触发铸造或重复交易，无需点击领取。
