架构不是永久承诺；改变时追加理由，并同步产品、接口和路线文档。

2026-10-31 前端探索：采用花叔 Design 的三方向流程，独立 HTML 原型不改变已有 API。A/B/C 待用户选择，尚无正式视觉决策。

第二轮：用户否定首轮三版，要求强烈作者风格；明确允许 Impeccable 与 Hallmark。新原型保存在 design-demos/round-2/，尚未确定正式视觉方向。

第三轮：保留第二轮 B 的单件浏览、“不像他就换一个”的交互方向；视觉改为成熟、低饱和、极客/加密文化，去除卡通。遵从用户要求先出首页图片，选定后再实现前端。

第四轮纠正：作品风格与平台风格分开。卡通等多样风格允许作为作品内容；网站要有稳定独立的视觉规则。逐件浏览不再硬性限定。用同一组混合作品生成多件并列展示的首页图片，先确认平台身份再实现。

第五轮：首页以精品店的精选与克制为目标，减少首屏作品密度、标签和表单，保持异质作品兼容。用首页图片先确定表达；尚未批准具体视觉方向。

第六轮：依用户要求进行六种设计 Skill 的方法对比，以相同产品约束和图片交付比较。Skill 指导与 ImageGen 绘图分工明确，未选择生产视觉；辅助/修补/发布类 Skill 按用途归类。
